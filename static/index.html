The method

How it works

  1. Read the claim

    A function called verify_token promises to verify something. We take note of what its name and comment promise.

  2. Compare to the code

    Then we read what it does and score the gap: a Lie Score, a CVSS 3.1 severity and an OWASP category.

  3. Attack it

    The bundled sample is attacked for real in a sandbox. Your own code gets a prediction, marked as one.

  4. Fix and attack again

    Apply the patch and replay the same attack. If it is blocked, the fix is verified.
